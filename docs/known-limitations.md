# Known limitations

One list of what the product does not do, or does only in part, grouped by area. For each item: what the
limitation is, why it exists, and what a user or operator sees. Nothing here is softened: if a document says
"not implemented", it is not. Statuses of features are in [status.md](status.md) and
[requirements-checklist.md](requirements-checklist.md); fixes for symptoms are in
[troubleshooting.md](troubleshooting.md).

## Page setup and the editor

| Limitation                                                                                           | Why                                                                                                                                                                                                                                                                                                                                                                                   | What you see                                                                                                                                                                                                       |
| ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **No pagination.** The document is one continuous sheet with the real width and margins of the paper | Page breaks on screen would need a layout engine that splits blocks across pages; ProseMirror has none. Page breaks appear only when printing                                                                                                                                                                                                                                         | A long document is one tall sheet; the print view breaks pages                                                                                                                                                     |
| **No first-line or hanging indent markers on the ruler**                                             | They need a per-paragraph length attribute, which is a schema change and a schema version. The schema's block `indent` is a whole-block level, not a length                                                                                                                                                                                                                           | The ruler has margin markers only                                                                                                                                                                                  |
| **Only A4 and Letter**                                                                               | `PAGE_SIZES` in `packages/contracts/src/page.ts` has two entries                                                                                                                                                                                                                                                                                                                      | No Legal, A3 or custom size                                                                                                                                                                                        |
| **Header and footer spacing is stored but not rendered**                                             | `headerSpacing` and `footerSpacing` are validated and kept in the document, but there are no headers or footers to space                                                                                                                                                                                                                                                              | They have no visible effect                                                                                                                                                                                        |
| The web print preview ignores the paper colour                                                       | Paper is white in the print view                                                                                                                                                                                                                                                                                                                                                      | A cream or grey page prints white                                                                                                                                                                                  |
| **Unsupported content pauses the whole window**, not single nodes                                    | A client with an older schema keeps content it cannot render but erases attributes it does not know when it edits the node. Per-node placeholders would need a patched collaboration binding that maps unknown elements to a placeholder and back without rewriting them; a mistake there deletes content, which is what the feature exists to prevent ([decisions.md](decisions.md)) | A notice names what was found ("2 blocks of a type this version does not know: callout"), editing is paused in that window, and it resumes by itself when the content is gone. The content is kept in the document |
| An editor can deny service to readers                                                                | Anyone with edit access can write extreme values (a table span of a billion columns) or make a document enormous. The 8 MiB state size is a log warning, not a limit                                                                                                                                                                                                                  | A document can become unusable for the people who open it. Give edit access only to people you trust                                                                                                               |
| Search covers titles only                                                                            | By design                                                                                                                                                                                                                                                                                                                                                                             | Document search does not look into content                                                                                                                                                                         |
| The document list is capped at 500 documents per view and is not paginated                           | Fixed limit in `routes/documents.ts`                                                                                                                                                                                                                                                                                                                                                  | Documents beyond the first 500 in a view are not listed                                                                                                                                                            |
| English only                                                                                         | No localisation layer                                                                                                                                                                                                                                                                                                                                                                 | All interface text is English                                                                                                                                                                                      |
| Three toolbar menus use a native `<select>` (block type, font size, code language)                   | Native popups on Windows are separate windows that private mode does not cover                                                                                                                                                                                                                                                                                                        | They show option names, not document text                                                                                                                                                                          |

**Fixed on 2026-11-12: simultaneous Enter.** Earlier versions of this list included "Simultaneous Enter by
several editors converges on wrong content". It was a caret-placement fault in the editor binding, not a
fault in the shared document, and it is fixed; see [testing.md](testing.md) section 5.1.

## Version history

| Limitation                                                                              | Why                                                                                                                                                                                                             | What you see                                                                                                  |
| --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **History starts at the upgrade** for existing documents                                | Earlier changes were never recorded per person (the update log has no actor and is compacted)                                                                                                                   | "History starts here" at the first change after the upgrade. Nothing earlier can be shown                     |
| **Character counts are approximate**                                                    | When blocks are split or merged the editor reports the text as removed and inserted again                                                                                                                       | A small edit can look larger than it was                                                                      |
| **Formatting is not in the text diff**                                                  | The diff compares the plain text of top-level blocks                                                                                                                                                            | Formatting, page settings and image changes appear in the row's summary, not in the "Changes" view            |
| **The "pasted" label is a heuristic and untrusted**                                     | The label comes from a hint the browser sends (accepted if the next change follows within 5 seconds) or from size (about 200 or more characters in one transaction). The hint can be sent by any editing client | A row can be labelled "Pasted content" for typed text, and a paste can be missed. It is wording, not proof    |
| Client time is not trusted                                                              | Only server clocks order and group rows. Offline changes appear when they reach the server                                                                                                                      | An offline change shows the time it arrived; the client's claimed time is shown as unverified                 |
| History is for administrators only                                                      | Candidates, interviewers and guests are refused by the server. `candidateCanViewHistory` is stored and reported, and gates no history route                                                                     | Only people who manage the document see "Version history"                                                     |
| History rows are never rewritten and are removed only by retention or with the document | Append-only by design. `HISTORY_RETENTION_DAYS` defaults to 0 (keep everything)                                                                                                                                 | The table grows without bound unless a retention period is set ([database-schema.md](database-schema.md))     |
| A rolled-back server does not record history                                            | The older version does not know the table                                                                                                                                                                       | Edits made meanwhile are saved but absent from history; the newer server writes a new starting row afterwards |

## Uploads and files

| Limitation                                     | Why                                                                                                                                                                       | What you see                                                                                                                                                   |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **No resumable or chunked upload**             | The largest file is 25 MiB; restarting one file is cheap and a second upload protocol was rejected ([decisions.md](decisions.md))                                         | A failed upload starts again from the beginning. Transient failures are retried automatically with backoff (8 attempts); "Waiting to retry" is shown meanwhile |
| **No malware scanning**                        | Not built. Files are checked by content type, size and, for images, dimensions, and are served as downloads with `nosniff`                                                | An infected attachment that passes the checks is stored and offered to everyone with access                                                                    |
| A single stored file cannot be deleted at once | Retention deletes a file after `ASSET_GRACE_DAYS` of being unreferenced by the document, every snapshot and every retained history row; there is no delete-asset function | To remove a file at once, the document has to be moved to the trash and deleted permanently                                                                    |
| SVG with editor metadata is rejected           | Strict allow-list                                                                                                                                                         | An SVG exported by a drawing tool with its own metadata is refused; export plain SVG                                                                           |
| Remote images are never fetched                | Fetching would let a document make the server or the reader contact other sites                                                                                           | A pasted image that points to another site becomes a labelled link                                                                                             |

## Desktop app

| Limitation                                                                                         | Why                                                                                                                                                                                                                                                                                               | What you see                                                                                                                                                                                                    |
| -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **No silent self-update**                                                                          | Replacing the running app needs signed builds so the operating system can vouch for the replacement; none exist, and an unsigned updater is what a hostile server would want                                                                                                                      | The app checks, downloads on request, verifies size and SHA-256, then shows the file; the user installs it                                                                                                      |
| **Builds are unsigned until credentials exist**                                                    | No code-signing certificate and no Apple Developer account have been provided. Desktop release 0.1.0 (2026-11-12) is unsigned and not notarised                                                                                                                                                   | Windows SmartScreen and macOS Gatekeeper warn. The download page says "Unsigned build". The macOS arm64 zip started in the CI launch check, but a Mac may still refuse an unsigned download                     |
| **Linux has no AppImage**                                                                          | `appimagetool` and FUSE are not part of the pipeline                                                                                                                                                                                                                                              | Linux packages are `.tar.gz` and `.zip`; the Linux x64 package was not built on this host                                                                                                                       |
| An interrupted update download starts again                                                        | Resume of the update download is not implemented (resumable `Range` downloads exist on the server for browsers)                                                                                                                                                                                   | A restarted download                                                                                                                                                                                            |
| **Capture exclusion depends on the OS and display server and is unverified for every meeting app** | It is a request to the operating system. Microsoft documents the underlying Windows function as not a security feature; on macOS ScreenCaptureKit-based capture ignores it; on Linux it may be unavailable. The compatibility matrix has no verified entry                                        | Every cell of the matrix reads "Not tested". Treat the panel as visible in a screen share unless a recorded test for your setup says otherwise                                                                  |
| **Windows and macOS have only been launch-tested in CI**                                           | The only host is headless Linux; CI launched the packaged app on its own OS for 20 seconds (Windows x64, macOS arm64, macOS x64), and nobody operated it by hand. Windows arm64 and Linux arm64 were never started on their own architecture in CI. The Windows `.exe` installer was not produced | Transparency, click-through, tray and menu bar, shortcuts, focus, multiple monitors, key stores, deep links, installers, capture exclusion and the diagnostics module are all "not tested" on Windows and macOS |
| Linux is a test platform, not a product target                                                     | No capture exclusion, tray availability cannot be detected, no `.desktop` file or URL-scheme registration is shipped                                                                                                                                                                              | Packages exist and start under Xvfb; nothing else is claimed                                                                                                                                                    |
| The tray menu has no "Check for updates"                                                           | The tray labels are the owner's pinned specification                                                                                                                                                                                                                                              | Updates are checked in Settings, Updates                                                                                                                                                                        |
| OS-drawn surfaces are outside every window                                                         | Input-method candidate windows, drag images, the attachment save dialog and the server-change dialog are drawn by the OS                                                                                                                                                                          | They can be visible in a capture even when the panel is not                                                                                                                                                     |
| A notification may not appear on Windows                                                           | A toast may need a Start-menu shortcut carrying the app's AppUserModelID, and the NSIS installer cannot set that ID without a plug-in ([notes/desktop.md](notes/desktop.md))                                                                                                                      | The tray tooltip and "Show" always work                                                                                                                                                                         |
| Mode switch opens a new window and connection                                                      | Design                                                                                                                                                                                                                                                                                            | A second or two; refused while changes are unsaved                                                                                                                                                              |
| Candidates cannot use the desktop app                                                              | Enforced by the server for interview candidates (the desktop handoff answers 403) and the web app hides the control                                                                                                                                                                               | "Open in Desktop" is not shown to a candidate                                                                                                                                                                   |

## Service API, interview sessions and webhooks

| Limitation                                                                                       | Why                                                                                                                                                                             | What you see                                                                                           |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **`candidateCanShare` has no effect**                                                            | It is stored and reported, but no participant can create share links (that needs a workspace administrator)                                                                     | Setting it to true changes nothing                                                                     |
| **The admin UI cannot create an interview session**                                              | Creation is through the API (`POST /api/v1/interview-sessions`)                                                                                                                 | `/admin/interview-sessions` lists and manages sessions ("Sessions are created through the API")        |
| **`document.first_edited` fires on the first edit after the session was created**                | It is emitted when a loaded document receives its first applied edit; a database claim makes it fire once per session. It does not say who edited, or that the candidate edited | The event can be caused by an interviewer's edit or by any other editor, not necessarily the candidate |
| **Idempotent replay window is 24 hours**                                                         | Records are deleted after 24 hours                                                                                                                                              | The same key after that creates a second session                                                       |
| An idempotency claim older than 120 seconds can be taken over while the first request still runs | A crashed request must not block a key forever                                                                                                                                  | On a very slow request a duplicate may be created                                                      |
| Document titles are checked for uniqueness in code, not by a constraint                          | Two simultaneous creations with identical inputs can collide                                                                                                                    | Two documents with the same title (the check reduces confusion; it does not prevent it)                |
| No webhook secret rotation                                                                       | Secrets are fixed at creation                                                                                                                                                   | Create a new endpoint and delete the old one                                                           |
| Webhook delivery is at least once and has no retention                                           | Receivers must deduplicate on the event id; nothing deletes old deliveries                                                                                                      | Duplicate deliveries are possible; the delivery table grows                                            |
| Webhook targets must be public https addresses in production                                     | SSRF protection: loopback, private, link-local and reserved addresses are refused at registration and at connect time; redirects are failures                                   | A webhook to an internal host is refused                                                               |
| Changing `SESSION_SECRET` breaks stored webhook secrets and idempotent replays                   | They are encrypted with a key derived from it ([deployment.md](deployment.md#rotating-session_secret))                                                                          | Deliveries fail with "The endpoint secret cannot be decrypted." until endpoints are recreated          |

## Multi-instance mode

From [scaling.md](scaling.md) and the code.

| Limitation                                                                                                                                                       | Why                                                                                                                                             | What you see                                                                                           |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Not verified: instances on different hosts, a shared network file system, TLS between instances, Redis Sentinel or Cluster, a balancer with active health checks | Only a single-host Compose trial and process-level tests were run                                                                               | The forwarded hop is plain HTTP on the private network                                                 |
| **Redis is a dependency of new collaboration connections**                                                                                                       | Tickets and ownership leases live there                                                                                                         | While Redis is away: open documents keep saving, new connections retry, `/api/ready` is 503            |
| **Redis is a trust root**                                                                                                                                        | Whoever can write to it can redirect sockets and read or forge tickets                                                                          | Keep it private and password protected                                                                 |
| **Rate limits fail open when Redis is unreachable**                                                                                                              | Refusing every sign-in during a Redis restart would turn a helper's failure into an outage                                                      | A short period without throttling                                                                      |
| `RATE_WS_UPGRADE_PER_MINUTE` is counted per instance                                                                                                             | Not moved to Redis                                                                                                                              | The effective limit is that value times the number of instances a client address can reach             |
| Assets and releases need shared storage; **no S3 storage adapter**                                                                                               | The storage interface exists (`src/assets/storage.ts`), an S3 implementation does not                                                           | Every instance must mount the same directory                                                           |
| Release file checks are per process                                                                                                                              | Each instance hashes its own copy of the shared files; only one `Range` is honoured (several ranges are answered with the whole file)           | More disk reads; a multi-range request gets the full file                                              |
| A request to a stopped instance can fail until the balancer notices                                                                                              | Measured once with nginx: 8 of 40 requests failed in a 2 second window; `proxy_connect_timeout 1s` was added afterwards and **not re-measured** | Plain API calls in that window can fail; collaboration clients reconnect by themselves                 |
| A killed instance's documents are unavailable until its lease expires                                                                                            | `CLUSTER_LEASE_TTL_SECONDS` (default 10)                                                                                                        | Reconnecting clients are refused and retry for up to that long; acknowledged edits are in the database |
| All sockets can land on one instance if the balancer does not share connection counts                                                                            | nginx workers counted separately until a `zone` line was added in `deploy/scale/nginx.conf`                                                     | Uneven load                                                                                            |
| No capacity claim                                                                                                                                                | `COLLAB_MAX_CONNECTIONS=1000` is a limit, not a measured capacity. Measured results are only in [load-test-report.md](load-test-report.md)      | n/a                                                                                                    |

## Capacity and limits that were measured

Numbers and method: [load-test-report.md](load-test-report.md). They come from one shared host over
loopback.

| Limitation                                                                              | Why                                                                                                                                                                                                                                          | What the user sees                                                                        |
| --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **Reconnecting after a server instance is replaced can take about 9 s for some people** | Measured p95 8.7–8.9 s behind a simple TCP proxy (objective: 5 s). The server hands documents over at once; failed attempts at the proxy plus the client's retry delays make up the rest. Not measured behind a balancer with health checks. | "Reconnecting…" for several seconds; typing continues and is sent afterwards.             |
| **The document size limit is a warning, not a stop**                                    | `LIMIT_MAX_DOCUMENT_STATE_BYTES` (8 MiB) is only logged. A 21 MB document was accepted; opening it took 0.3–0.5 s and about 100 MB of server memory.                                                                                         | Nothing. A very large document makes every open slower and uses server memory while open. |
| **A one-hour soak test was not run**                                                    | 12 minutes were measured; resident memory rose by 71 MB, heap showed no trend.                                                                                                                                                               | Unknown beyond 12 minutes under that load.                                                |
| **"One user cannot starve the others" was not measured**                                | The paste-burst scenario was not run. Per-socket frame budgets and rate limits exist and behaved as designed where they were exercised.                                                                                                      | Unknown under a deliberate flood by an editor.                                            |
| **Many people reconnecting at the same second slow the ticket endpoint**                | 1,000 simultaneous requests: p95 369 ms on one instance with the default pool of 10 connections.                                                                                                                                             | A slightly slower reconnect after a mass disconnect.                                      |

## Operations

| Limitation                                                                                                                                   | Why                                                                                                                                                                                                                                        | What you see                                                                                  |
| -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| **Backups are not automated**                                                                                                                | `scripts/backup.sh` is run by hand or from a cron job you set up. No schedule, rotation, encryption or off-host copy is provided                                                                                                           | RPO equals the age of the last backup. See [incident-response.md](incident-response.md)       |
| No point-in-time recovery                                                                                                                    | WAL archiving is not configured                                                                                                                                                                                                            | Recovery goes to the moment of a backup                                                       |
| A restore into the live deployment has not been rehearsed                                                                                    | The restore script was rehearsed in throw-away projects                                                                                                                                                                                    | The first real restore would be the first on that project                                     |
| **No tracing**                                                                                                                               | No OpenTelemetry exporter or collector                                                                                                                                                                                                     | Requests are correlated by request id in logs, audit events and error bodies only             |
| Metrics are not stored                                                                                                                       | `/metrics` is scraped by a system you provide                                                                                                                                                                                              | There are no historical graphs unless you run Prometheus                                      |
| **No e-mail delivery**                                                                                                                       | By design: invitation and share links are copied and sent by a person                                                                                                                                                                      | A forgotten password is reset by the operator (`reset-password`)                              |
| No multi-factor authentication, single sign-on or e-mail verification                                                                        | Not built                                                                                                                                                                                                                                  | Sign-in is by password only                                                                   |
| One workspace; every administrator can read every document                                                                                   | Single-tenant design                                                                                                                                                                                                                       | No finer-grained administration                                                               |
| Changes made directly in the database reach open connections late                                                                            | A direct change is picked up by the periodic check                                                                                                                                                                                         | Up to `COLLAB_SWEEP_INTERVAL_SECONDS` (30 s) later. Changes through the product are immediate |
| A client with more than 4 MiB of offline changes cannot send them in one frame                                                               | `LIMIT_MAX_COLLAB_MESSAGE_BYTES`                                                                                                                                                                                                           | The connection closes with code 1009; the work stays in the client's recovery draft           |
| The retention job reads every document state to collect asset references                                                                     | Its cost grows with the number and size of documents; not measured                                                                                                                                                                         | A slow cleanup on a large installation                                                        |
| No retention for webhook deliveries, API keys, interview sessions, participants (including candidate e-mail addresses) and download counters | Only some tables have retention rules ([database-schema.md](database-schema.md))                                                                                                                                                           | Those rows stay until their document or endpoint is deleted                                   |
| `deploy/admin-credentials.txt` still exists                                                                                                  | Created on 2026-11-11 with the first administrator                                                                                                                                                                                         | The owner should delete it once the password is stored elsewhere                              |
| CI is not a substitute for native testing                                                                                                    | `ci.yml` and `desktop-release.yml` have been executed on GitHub (2026-11-12): CI passed on `c599e4e`, and release run 43195585865 succeeded on Windows, macOS (arm64 and x64) and Linux runners after three earlier failed runs were fixed | They run builds, tests and a 20-second launch check; they do not exercise the app by hand     |
| Cloudflare account settings are still open                                                                                                   | They can be changed only in the Cloudflare account ([deployment.md](deployment.md#cloudflare-settings))                                                                                                                                    | A console error from Web Analytics injection; a four hour browser cache of two small files    |
| Manual use of the app on Windows and macOS, real Safari, real phones and screen readers are untested                                         | The host is headless Linux and no one has operated the app on those systems                                                                                                                                                                | See [testing.md](testing.md) section 6                                                        |
